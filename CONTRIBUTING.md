# 🤝 Contributing to RiPlay

## 🛠️ Improve the project

Pull requests are welcome. Describe the problem or improvement and how you verified the change. 

This repository is a fork of [fast4x/RiPlay](https://github.com/fast4x/RiPlay). Use this repository for fork-specific changes and the upstream project for general changes.

## 📜 Clone the repo

    git clone -b main --single-branch --recursive https://github.com/NEVARLeVrai/RiPlay.git

## ✅ Verify your changes

Follow the README build setup and identify which platform and playback path you tested.

## 📬 Open a pull request

Keep the change focused and link the related issue when there is one. Include verification steps and screenshots for visual changes when applicable.
